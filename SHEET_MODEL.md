# LawVault v5 — Google Sheet data model

The Google Sheet is LawVault's database. The public site reads it
(read-only, via the gviz JSON endpoint); the admin panel writes to it
only through the Apps Script web app, which checks the admin
credentials server-side. Nothing else writes to the Sheet.

`apps-script/Code.gs` → `setupSheets()` creates every tab below with
these exact headers, and seeds the defaults. Tab names and header
names are the contract: renaming them breaks the site and the panel.

## How values are read

- Text cells are read as-is. Leading/trailing spaces are trimmed.
- `TRUE` / `FALSE` (or `true` / `yes` / `1`) mean enabled/yes.
  Anything else means disabled/no.
- Dates: type them as `YYYY-MM-DD HH:MM` (for example
  `2026-11-20 09:00`). The site treats them as Asia/Kolkata local
  time. A date-typed cell works too.
- Empty cells mean "not set". The site falls back to the local
  `data/content.json` / `data/site-config.json` for any tab that
  cannot be fetched, so the site always renders.
- Links must start with `https://`. The site and the script both
  reject anything else.

## Status values

| Status      | Meaning                                     |
| ----------- | ------------------------------------------- |
| Draft       | Admin is preparing it; not shown publicly   |
| Pending     | Awaiting verification; shown only in the    |
|             | Pending & Unverified section                |
| Demo        | Placeholder material; shown with a DEMO     |
|             | badge                                       |
| Published   | Checked and shown on the public website     |
| Archived    | No longer displayed                         |

Only `Published` (and `Demo`, clearly labelled) rows appear in the
public sections. A row with `enabled = FALSE` never appears, whatever
its status. Scheduled rows (`publish_at` in the future) stay hidden
until their publish time; expired rows (`expires_at` passed) disappear
from display without being deleted.

## Tabs

### settings — key/value site settings

| Column | Meaning |
| ------ | ------- |
| key    | Setting name (see below) |
| value  | Setting value |

Known keys (unknown keys are ignored):

| key | Meaning | Example |
| --- | ------- | ------- |
| site_title | Site name in the browser title | LawVault |
| site_tagline | Small text under the logo | LLB CLASS LIBRARY |
| welcome_title | Welcome banner heading | Your LLB Study Space |
| welcome_subtitle | Welcome banner subheading | Welcome to LawVault — … |
| footer_tagline | Footer tagline | Study • Revise • Prepare • Succeed |
| main_drive_folder | Main Drive folder link (https://) | https://drive.google.com/drive/folders/… |
| default_mode | `dark` or `light` | dark |
| default_color | One of: emerald, teal, ocean, violet, amber | emerald |
| festival_auto | `TRUE` / `FALSE` — automatic festival themes | TRUE |
| exam_date | Exam date (`YYYY-MM-DD`) — only then does the countdown show | (empty = no countdown) |

Festival date ranges and colour palettes stay in
`data/site-config.json` (Phase 2 will move them to the Sheet).

### daily_notes — Today's Notes

| Column | Meaning |
| ------ | ------- |
| id | Unique id (generated by the script if empty) |
| title | Note title (required) |
| description | Short description |
| drive_link | Google Doc/folder link, https:// (required) |
| subject | Subject name, e.g. Law of Contract |
| publish_at | Publish date/time; future = scheduled |
| expires_at | Expiry date/time; empty = 24 hours after publish |
| important | TRUE = shown with an Important badge |
| enabled | TRUE / FALSE |
| status | Draft / Published / Archived |
| created_at | Set by the script |
| updated_at | Set by the script |

Expiry removes the note from the Today's Notes display only. It never
deletes the Google Drive document.

### announcements — Latest Updates + notification bell

| Column | Meaning |
| ------ | ------- |
| id | Unique id |
| title | Announcement title (required) |
| description | Announcement text |
| badge | `Important` or `New` (empty = no badge) |
| pinned | TRUE = pinned to the top |
| publish_at | Publish date/time; future = scheduled |
| expires_at | Expiry date/time; empty = no expiry |
| enabled | TRUE / FALSE |
| status | Draft / Published / Archived |
| created_at | Set by the script |
| updated_at | Set by the script |

### semesters — Semester tabs

| Column | Meaning |
| ------ | ------- |
| id | `sem-1` … `sem-7` |
| number | 1–7 |
| label | Display label, e.g. Semester 1 |
| configured | TRUE = subjects for this semester are shown; FALSE = the tab shows "Not configured yet" |
| enabled | TRUE / FALSE |
| order | Display order (1 first) |

### subjects — Subject/unit cards inside a semester

| Column | Meaning |
| ------ | ------- |
| id | Unique id |
| semester_id | `sem-1` … `sem-7` (required) |
| name | Subject name, e.g. Law of Contract (required) |
| icon | Emoji icon for the card (optional) |
| unit | Unit label, e.g. Unit 2 |
| description | Topic, e.g. Capacity & Vitiating Factors |
| drive_link | Google Doc link, https:// (required) |
| enabled | TRUE / FALSE |
| order | Display order within the semester |

The public card heading is the subject name; the unit and description
are shown under it.

### case_laws — Case Law Library

| Column | Meaning |
| ------ | ------- |
| id | Unique id |
| title | Case title (required) |
| citation | Citation, exactly as published |
| court | Court name |
| year | Year |
| subject | Subject, e.g. Law of Tort |
| facts | Facts |
| issues | Legal issues |
| judgment | Judgment |
| ratio | Ratio decidendi |
| exam_relevance | Exam relevance note |
| drive_link | Source document link, https:// |
| important | TRUE = marked important |
| status | Draft / Pending / Demo / Published / Archived |

Never invent citations, years, courts, or judgments. Leave a field
empty if it is not known.

### papers — Previous Year Question Papers

| Column | Meaning |
| ------ | ------- |
| id | Unique id |
| title | Display title, e.g. 2024 question paper collection (required) |
| year | Exam year (required) |
| semester_id | `sem-1` … `sem-7` |
| subject | Subject |
| exam_type | e.g. End Semester / Supplementary |
| drive_link | Drive folder link, https:// (required) |
| status | Draft / Pending / Demo / Published / Archived |

Papers are shown newest year first.

### exam_prep — Exam Preparation cards

| Column | Meaning |
| ------ | ------- |
| id | Unique id |
| category | Card group, e.g. Important Questions (required) |
| title | Card title (required) |
| description | Card description |
| drive_link | Drive link, https:// |
| enabled | TRUE / FALSE |
| order | Display order |

The exam countdown date is the `exam_date` key in `settings`.
The revision checklist stays browser-local (each student's own
browser) and is not stored in the Sheet.

### pending — Pending & Unverified Content

| Column | Meaning |
| ------ | ------- |
| id | Unique id |
| title | Title (required) |
| description | Description |
| drive_link | Drive link, https:// |
| status | Draft / Pending / Demo / Verified / Archived |
| reason | Why it is unverified |
| created_at | Set by the script |

Only `Pending` and `Demo` rows are shown, always with the warning
styling. `Verified` rows are promoted by moving them to their real
section (daily notes, subjects, case laws, or papers) — the admin
panel does not auto-promote them.

### contacts — Contact & Feedback cards

| Column | Meaning |
| ------ | ------- |
| id | Unique id |
| label | Card title, e.g. Message Admin (required) |
| kind | Card kind: message, feedback, broken-link, incorrect, suggest, community |
| destination | Destination link, https:// (empty = card stays disabled) |
| enabled | TRUE / FALSE — a card only becomes clickable when enabled AND a destination is set |
| order | Display order |

Unconfigured cards appear greyed out on the public website.

### activity_log — Activity history (read-only from the panel)

| Column | Meaning |
| ------ | ------- |
| timestamp | When the action happened (ISO) |
| admin | Administrative code used |
| action | add / update / delete / ping |
| module | Tab the action touched |
| detail | Entry id, or the error message |
| result | ok / failed |

The script appends here on every request, including failed logins.
The panel never writes to this tab directly.
